# Срочный трудовой договор № С-2024/18

г. Краснодар                                                  «11» апреля 2024 г.

ООО «АгроЮг», именуемое в дальнейшем «Работодатель», в лице генерального директора Нестерова П.А., действующего на основании Устава, с одной стороны, и гражданин Российской Федерации Морозов Илья Павлович, именуемый в дальнейшем «Работник», с другой стороны, заключили настоящий трудовой договор о нижеследующем:

## 1. Предмет договора
1.1. Работник принимается на работу в ООО «АгроЮг» на должность специалиста по документообороту.
1.2. Место работы Работника: офис Работодателя по адресу: г. Краснодар, ул. Северная, д. 245, офис 31.
1.3. Работа по настоящему договору является для Работника основной.

## 2. Срок договора
2.1. Настоящий трудовой договор заключается сроком на 1 (один) год: с «15» апреля 2024 г. по «14» апреля 2025 г.
2.2. Срочный характер договора установлен по соглашению сторон.
2.3. Работодатель не относится к субъектам малого предпринимательства, численность работников Работодателя составляет 120 человек.
2.4. Работник не является пенсионером по возрасту, совместителем, студентом очной формы обучения, руководителем организации, творческим работником или лицом, для которого Трудовой кодекс Российской Федерации допускает заключение срочного договора только по соглашению сторон.
2.5. Иные основания заключения срочного трудового договора сторонами не указываются.

## 3. Условия оплаты труда
3.1. Работнику устанавливается должностной оклад в размере 62 000 (шестьдесят две тысячи) рублей в месяц.
3.2. Заработная плата выплачивается в сроки, предусмотренные правилами внутреннего трудового распорядка Работодателя.
3.3. Премии выплачиваются по решению Работодателя при наличии финансовой возможности.

## 4. Режим рабочего времени и отдыха
4.1. Работнику устанавливается пятидневная рабочая неделя с двумя выходными днями.
4.2. Продолжительность ежедневной работы составляет 8 часов.
4.3. Ежегодный оплачиваемый отпуск предоставляется в соответствии с графиком отпусков.

## 5. Права и обязанности сторон
5.1. Работник обязан вести входящую и исходящую корреспонденцию, регистрировать договоры и выполнять поручения руководителя отдела.
5.2. Работодатель обязан предоставить Работнику рабочее место и необходимые технические средства.
