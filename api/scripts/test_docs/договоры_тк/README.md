## Документы для проверки противоречий с ТК РФ

В этой папке содержатся пары «правильный / неправильный» письменных документов (трудовые договоры, приказы), позволяющие тестировать RAG-систему на поиск нарушений Трудового кодекса РФ.

### 1. Срочный трудовой договор
- **Правильная версия:** заключён на неопределённый срок либо срочный – с явным законным основанием (например, «на время сезонных работ»). Соответствует ст. 58, 59 ТК РФ.
- **Неправильная версия:** письменный договор со сроком 1 год и формулировкой «по соглашению сторон» без указания основания из ст. 59 ТК РФ.
  *Нарушение:* ст. 58 ТК РФ – срочный договор без законных оснований незаконен, общее правило – бессрочность.

### 2. Положение о выплате заработной платы
- **Правильная версия:** в трудовом договоре или локальном акте указаны две конкретные даты выплаты в месяц (например, 15 и 30 числа). Соответствует ст. 136 ТК РФ.
- **Неправильная версия:** письменное условие «заработная плата выплачивается один раз в месяц (аванс – по желанию работодателя)».
  *Нарушение:* ст. 136 ТК РФ – зарплата должна выплачиваться не реже чем каждые полмесяца.

### 3. Трудовой договор о сверхурочной работе
- **Правильная версия:** сверхурочная работа оформляется отдельным приказом при каждом случае, с письменным согласием работника и оплатой 1,5–2. Соответствует ст. 99, 152 ТК РФ.
- **Неправильная версия:** в самом трудовом договоре прописан пункт: «Работник обязуется выполнять сверхурочную работу без дополнительной оплаты по устному указанию руководителя».
  *Нарушение:* ст. 99 ТК РФ – требуется письменное согласие на каждый случай (нельзя заранее согласиться на все сверхурочные) и ст. 152 ТК РФ – запрещено лишать повышенной оплаты.
