# Трудовой договор № ТД-2024/64

г. Самара                                                     «21» мая 2024 г.

АО «Логистик-Поволжье», именуемое в дальнейшем «Работодатель», в лице директора филиала Захарова О.И., действующего на основании доверенности № 12 от «09» января 2024 г., с одной стороны, и гражданин Российской Федерации Кузнецов Артем Игоревич, именуемый в дальнейшем «Работник», с другой стороны, заключили настоящий трудовой договор о нижеследующем:

## 1. Предмет договора
1.1. Работник принимается на должность диспетчера транспортного отдела.
1.2. Место работы: филиал АО «Логистик-Поволжье» по адресу: г. Самара, ул. Кабельная, д. 7.
1.3. Работа по настоящему договору является основной.

## 2. Режим рабочего времени
2.1. Работнику устанавливается пятидневная рабочая неделя с двумя выходными днями.
2.2. Нормальная продолжительность рабочего времени составляет 40 часов в неделю.
2.3. Подписывая настоящий договор, Работник заранее соглашается выполнять сверхурочную работу по устному указанию руководителя транспортного отдела.
2.4. Дополнительное письменное согласие Работника на каждый случай сверхурочной работы не требуется.
2.5. Работодатель вправе привлекать Работника к сверхурочной работе в любой рабочий день при производственной необходимости.

## 3. Оплата труда
3.1. Работнику устанавливается должностной оклад в размере 70 000 (семьдесят тысяч) рублей в месяц.
3.2. Заработная плата выплачивается в сроки, установленные локальными нормативными актами Работодателя.
3.3. Сверхурочная работа включается в должностной оклад и не оплачивается дополнительно.
3.4. Работник подтверждает, что не будет требовать повышенной оплаты за часы работы сверх установленной продолжительности рабочего времени.

## 4. Права и обязанности сторон
4.1. Работник обязан выполнять трудовую функцию диспетчера, соблюдать правила внутреннего трудового распорядка и выполнять распоряжения непосредственного руководителя.
4.2. Работодатель обязан предоставить Работнику рабочее место и технические средства для выполнения трудовой функции.

## 5. Отпуск
5.1. Работнику предоставляется ежегодный основной оплачиваемый отпуск продолжительностью 28 календарных дней.
5.2. График отпусков утверждается Работодателем.
