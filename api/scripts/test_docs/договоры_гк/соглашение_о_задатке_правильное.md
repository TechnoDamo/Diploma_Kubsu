# Соглашение о задатке

г. Москва                                                      «10» мая 2024 г.

Гражданин РФ Николаев С.П., паспорт 45 10 123456, именуемый в дальнейшем «Покупатель», с одной стороны, и гражданка РФ Фёдорова М.Л., паспорт 45 11 654321, именуемая в дальнейшем «Продавец», с другой стороны, заключили настоящее соглашение о нижеследующем:

## 1. Предмет соглашения
1.1. В обеспечение исполнения обязательств по заключению в будущем договора купли-продажи квартиры, расположенной по адресу: г. Москва, ул. Цветочная, д. 10, кв. 45, Покупатель передаёт Продавцу денежную сумму в размере **150 000 (сто пятьдесят тысяч) рублей** в качестве **задатка**.
1.2. Указанная сумма входит в счёт причитающихся по основному договору платежей.

## 2. Последствия неисполнения
2.1. Если основной договор не будет заключён по вине Покупателя, сумма задатка остаётся у Продавца.
2.2. Если основной договор не будет заключён по вине Продавца, он обязан возвратить Покупателю сумму задатка в двойном размере — 300 000 (триста тысяч) рублей.

## 3. Срок действия
3.1. Основной договор купли-продажи подлежит заключению не позднее «01» июля 2024 г.
