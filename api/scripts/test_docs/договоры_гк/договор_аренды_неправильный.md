# Договор аренды нежилого помещения № А-2024/90

г. Москва                                                      «02» апреля 2024 г.

ООО «БизнесЦентр», именуемое в дальнейшем «Арендодатель», в лице генерального директора Козлова М.С., действующего на основании Устава, с одной стороны, и ООО «СтартапПлюс», именуемое в дальнейшем «Арендатор», в лице генерального директора Ивановой Е.А., действующей на основании Устава, с другой стороны, заключили настоящий договор о нижеследующем:

## 1. Предмет договора
1.1. Арендодатель передаёт, а Арендатор принимает во временное владение и пользование нежилое помещение.
1.2. Характеристики помещения: **часть складского помещения по адресу г. Москва, ул. Ленина, д. 15, примерной площадью около 80-90 кв. м.** Точные границы арендуемой части склада определяются по факту размещения товара Арендатора.
1.3. План или схема помещения сторонами не составлялись.

## 2. Срок аренды
2.1. Договор заключён сроком на 11 (одиннадцать) месяцев с даты подписания акта приёма-передачи.
2.2. По истечении срока аренды при отсутствии возражений сторон договор считается продлённым на тех же условиях на неопределённый срок.

## 3. Арендная плата
3.1. Ежемесячная арендная плата составляет 127 500 (сто двадцать семь тысяч пятьсот) рублей, включая НДС 20%.
3.2. Арендная плата вносится не позднее 5-го числа каждого оплачиваемого месяца.

## 4. Права и обязанности сторон
4.1. Арендодатель обеспечивает возможность размещения товара в пределах свободной площади склада.
4.2. Арендатор обязуется не загромождать проходы и проезды на территории склада.
