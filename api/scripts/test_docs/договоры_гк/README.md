# Документы для проверки противоречий с ГК РФ

В этой папке содержатся пары «правильный / неправильный» письменных документов, предназначенные для тестирования RAG-системы на поиск несоответствий статьям Гражданского кодекса РФ. Каждый неправильный документ нарушает конкретную норму, оставаясь при этом письменным.

## 1. Договор поставки товара
- **Правильная версия:** содержит все существенные условия (наименование товара, **количество**, срок поставки, цену). Соответствует ст. 432, 455 ГК РФ.
- **Неправильная версия:** договор письменный, но **отсутствует количество товара** (указано «партия» без цифр или единиц измерения).
  *Нарушение:* ст. 455 ГК РФ – количество является существенным условием; без него договор считается незаключённым.

## 2. Договор аренды нежилого помещения
- **Правильная версия:** объект аренды описан с точностью, позволяющей его идентифицировать (адрес, этаж, номер комнаты, площадь, кадастровый номер). Соответствует ст. 607 ГК РФ.
- **Неправильная версия:** объект указан как «часть склада» без схемы, плана или точных границ.
  *Нарушение:* ст. 607 ГК РФ – условие о предмете аренды не согласовано, договор незаключён.

## 3. Соглашение о задатке
- **Правильная версия:** письменный документ с заголовком «Соглашение о задатке», фразой об обеспечительной функции, суммой и сроком. Соответствует ст. 380 ГК РФ.
- **Неправильная версия:** расписка в получении **аванса** с фразой «в случае неисполнения аванс не возвращается», без явного названия «задаток».
  *Нарушение:* ст. 380 ГК РФ – аванс не является обеспечительным платежом; задатком признаётся только сумма, выданная по письменному соглашению с прямым указанием на задаток.
