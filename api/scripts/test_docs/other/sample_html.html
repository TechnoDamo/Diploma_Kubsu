Information Security Policy

This document outlines the information security framework for the organization. All employees must adhere to these policies to protect company assets.

Password Policy

  • Minimum length: 12 characters
  • Must include uppercase, lowercase, numbers, and symbols
  • Change every 90 days
  • No reuse of previous 10 passwords

Data Handling

Encryption at rest: All sensitive data must be encrypted using AES-256.

Encryption in transit: TLS 1.2 or higher is required for all network communications.

Backup policy: Critical data is backed up daily with 30-day retention.

Incident Response

  1. Identify and contain the incident
  2. Assess impact and notify stakeholders
  3. Remediate root causes
  4. Document lessons learned
